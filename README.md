# Archivo del Cine Clásico Universal

Práctica de **Bootstrap 6** para Programación web I (UTM). El sitio aplica la práctica paso a paso:

1. Estructura base con el CDN de Bootstrap 6, temas (`data-bs-theme`) e iconos.
2. Barra de navegación responsiva con menú lateral (`drawer`) en celular.
3. Sección principal (hero) con badge, títulos y botones centrados.
4. Catálogo con rejilla responsiva (`md:col-6`, `lg:col-4`) y tarjetas (`card`) con imagen, género, calificación y duración.

Las imágenes del catálogo están en la carpeta `images/` y se cargan con rutas relativas, así que se ven igual en la computadora y publicadas en GitHub Pages.
